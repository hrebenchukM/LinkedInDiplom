# Frontend Quick Start (No Backend)

Этот фронтенд можно запускать отдельно, без API и базы.
Авторизация в демо-режиме работает через `localStorage`.

## 1) Запуск локального сервера

Открой терминал в папке `frontend` и выполни одну из команд:

### Python
```bash
python -m http.server 5500
```

### Node.js
```bash
npx serve . -l 5500
```

## 2) Открыть в браузере

Перейди на:

`http://localhost:5500`

## Важно

- Не открывай страницы через `file://` (двойной клик по html).
- Используй именно локальный сервер (`http://localhost:...`).
- Если в браузере старый кэш, сделай `Ctrl+F5`.

## Что работает без бэкенда

- регистрация/вход (mock-режим),
- главная, профиль, сеть, вакансии, чат,
- сохранение данных пользователя, темы и языка в `localStorage`.
